# Landing V2 — Architecture cleanup & mobile motion

Дата: 2026-08-24  
Маршрут: `/landing-v2`  
Область: Blocks 01–08; Block 09 не менялся.

## Итог

Проведён correction pass без переработки визуального направления. В Block 07 очищен вход в сцену и убраны декоративные направляющие без смысловой функции. Для мобильных Blocks 01–08 добавлены отдельные GSAP/ScrollTrigger-сценарии нормальной прокрутки. Они не используют pinning, горизонтальный hijack или desktop-последовательности в уменьшенном масштабе.

## Block 07: архитектура

### Что было шумом

- координатные псевдолинии, проходившие по зоне интро;
- избыточная рамка поля источников;
- отдельные линии над слоями действий и аналитики, не объяснявшие переход;
- нижняя вертикальная линия без конечной смысловой точки.

### Что изменено

- до начала появления источников архитектурное поле скрыто, а H2 и лид остаются в чистой безопасной зоне;
- псевдокоординатные линии и финальная вертикаль выключены;
- снижена контрастность рамки поля источников;
- остались только линии, читаемые как отношения: источники → слой ИИ → действия; обратная связь обозначена текстовым направлением «сигнал обратно в процесс», без декоративного коннектора;
- финальная композиция больше не содержит отдельной вертикали без подписи или цели.

## Mobile motion

`prefers-reduced-motion` отделен: motion-ветки запускаются только при `no-preference`; при reduced motion содержимое остаётся доступным в статическом порядке.

| Блок | Поведение на mobile |
| --- | --- |
| 01 Hero | одноразовый мягкий вход текста, визуала и монитора |
| 02 Hidden cost | заголовок и строки реестра потерь последовательно проявляются при входе в блок |
| 03 Company context | заголовок и объединённый контекст появляются при прокрутке; исходная логика источников сохранена |
| 04 Knowledge | вопрос, источники, ответ и следующий шаг раскрываются по порядку |
| 05 Conversation | цитата, карточки фокуса и действие раскрываются каскадом |
| 06 Market | фразы, рыночный сигнал и переключатель раскрываются в последовательности |
| 07 Architecture | источники → акцентный сигнал → этапы → финальная формула раскрываются в обычном вертикальном потоке |
| 08 How we work | фраза, активная линия прогресса и этапы раскрываются при обычном scroll |

Все новые scroll-сцены ограничены мобильными media queries и используют `ScrollTrigger` без pinning. Desktop-анимация Blocks 04–07 сохранена.

## Адаптивность и QA

Проверено в Chrome на локальном dev-сервере:

- desktop 1440×900 и 1280×800: Block 07 без горизонтального overflow, интро без пересекающих его направляющих;
- mobile 390×844: Hero, контекст, архитектура и процесс прокручены через реальный Chrome scroll; horizontal overflow не найден;
- mobile 360×800 и 320×568: horizontal overflow не найден.

В управляемом Chrome CSS viewport масштабируется относительно физического размера окна; проверки переполнения выполнялись по фактическим `innerWidth`/`scrollWidth` каждого окна.

## Производительность и доступность

- Анимации создаются в `gsap.matchMedia()` и корректно уничтожаются при смене breakpoint/размонтаже.
- На mobile нет зафиксированных scroll-сцен и нет бесконечных циклов.
- Включён `prefers-reduced-motion` fallback.
- В Hero добавлен перенос длинных слов на узких экранах, чтобы исключить визуальное обрезание строки.
